# Prispevanje k projektu LinuxGNETX

Hvala za zanimanje za projekt LinuxGNETX!

LinuxGNETX je odprtokodni projekt. Dobrodošli so predlogi, popravki napak, izboljšave skript, dopolnitve dokumentacije in nove funkcionalnosti.

## Kako lahko prispevate?

K projektu lahko prispevate na več načinov:

- Prijavite napako ali težavo pri namestitvi oziroma uporabi.
- Predlagate novo funkcionalnost.
- Izboljšate obstoječe Bash skripte.
- Popravite ali dopolnite dokumentacijo.
- Preizkusite projekt na različnih sistemih in sporočite rezultate.

## Prijava napak in predlogov

Napake in predloge lahko oddate prek GitHub Issues:

https://github.com/dguttierrez/LinuxGNETX/issues

Pri prijavi napake navedite:

- Različico operacijskega sistema.
- Opis težave in korake za ponovitev.
- Morebitna sporočila o napakah.
- Predlog rešitve, če ga imate.

Pred objavo odstranite gesla, žetone, zasebne ključe in druge občutljive podatke.

## Prispevanje kode

1. Ustvarite Fork projekta na GitHubu.
2. V svojem repozitoriju ustvarite novo vejo.
3. Izvedite spremembe.
4. Preverite delovanje spremenjenih skript.
5. Oddajte Pull Request v izvirni repozitorij.

Prosimo, da so spremembe pregledne, smiselno dokumentirane in omejene na namen posameznega Pull Requesta.

## Smernice za skripte

- Uporabljajte Bash in običajna Linux orodja, kjer je to mogoče.
- Upoštevajte združljivost s sistemi, ki jih projekt podpira.
- Ne vključujte gesel, dostopnih žetonov ali zasebnih ključev.
- Večje spremembe pojasnite v dokumentaciji.
- Pred oddajo preverite sintakso skript, na primer z `bash -n`.

## Jezik

Primarni jezik projekta in dokumentacije je slovenščina.

Prispevki v slovenščini so zaželeni, sprejemamo pa tudi predloge v angleščini.

## Pregled in sprejem prispevkov

Vsak Pull Request bo pred vključitvijo pregledan. Avtor projekta si pridržuje pravico do sprejetja, zavrnitve ali predlaganja dodatnih sprememb.
